# V0.38 九州行旅

V0.38 将原始规则中的五大地域与“跑商、护送”从背景设定升级为可持续游玩的跨域系统。数值仍由本地规则引擎结算，不依赖联网服务。

## 可玩闭环

- 九州舆图集中展示东洲、南疆、西漠、北原和中州的准入境界、危险度、行程、特产与求购。
- 玩家选择目的地后进入重大抉择，可随商队同行或御风独行，也可取消而不消耗资源。
- 远行按路线推进数月，寿元、NPC、天下事件、委托期限和拍卖期限全部同步变化。
- 抵达后可查看当地探索点与区域坊市；隔空探索会被规则引擎拒绝。
- 五域供需与民生共同决定价格，货物成本和商队路费进入商路盈亏账簿。
- 四海商会新增跨域护运委托，把地图移动接入循环任务与赚钱路径。

## 界面与兼容

- 五域采用响应式卡片组件，地域身份、风险、准入、行程、特产和求购不再挤成一行。
- 坊市新增本地特产、热门求购和累计商路盈亏摘要。
- 成果巡览增至 18 页，新增真实跨域行旅待选状态。
- V0.37 及更早 JSON 存档会自动补全东洲踏访、空行旅记录和空商路账簿。

## 验证范围

- 境界准入、中文境界解析、路线成本、取消无消耗、数月时间推进、寿元联动。
- 区域买卖价、成本基础、商队路费、跨域盈亏和当地探索限制。
- FastAPI 快照、成果巡览隔离、前端类型检查、生产构建与桌面/手机浏览器验收。
