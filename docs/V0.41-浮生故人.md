# V0.41 浮生故人

V0.41 将原始文案中“NPC 有自己的境界、寿元和人生轨迹”落为持久化规则。人物不再只按月随机游历，而会在九州岁月中真实成长、破境、受伤、老去和辞世。

## 生命周期

- 六位核心人物拥有独立年龄、寿元、动态大境界和小境界、修行积累、伤势、活动、所在地及在世状态。
- 每次跨年会统一结算人物年龄和年度修行；小境界达到条件后自然推进。
- 大境界突破由存档种子稳定判定。无人护道时，人物会自行渡劫，可能成功、受创闭关或在高境界重劫中陨落。
- 新境界会同步提高寿元上限；寿元耗尽且无力破境时会真实坐化。

## 护道之约

- 好感达到相识的人物在大境界破关或寿元将尽时，会送来一封六个月有效的护道书。
- `赠丹` 消耗当前大境界所需的破境丹，成功率大幅提高。
- `护持` 消耗玩家 30 点灵力并增加功德；若失败，玩家可能受到天劫反噬。
- `守候` 不消耗资源，也不会获得额外成功率。逾期未回应时按此路线自动结算。
- 三种方案都只由玩家亲自选择，不会暗中消耗乾坤袋物品。

## 故人名录

- 人物辞世后不能继续交谈、赠礼、论道、结契或双修。
- 已故道侣会从当前契约中移除，关系标记转为“故人”。
- 享年、最终境界、死因和关键生平永久写入存档，并在人物页的故人名录中保留。

## 界面与兼容

- 人物页以寿元仪表、境界与关系标签、所在活动、状态、护道书和折叠生平组成，不把信息压成单行文字。
- 成果巡览的“浮生故人”页展示一封真实可判定的寿元告急护道书；巡览模式不会修改正式存档。
- V0.40 及更早存档缺少的生命周期字段会使用安全默认值；已有所在地、伤势与修行积累继续保留。
- Python 规则引擎仍是年龄、寿元、概率、资源与生死结果的唯一权威来源。
