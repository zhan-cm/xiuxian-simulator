# V0.58 便携卷宗与安全迁移

V0.58 解决玩家升级正式版、移动游戏目录或更换电脑时的存档迁移问题。继续使用易备份、易修复的本地 JSON，不引入对单机游戏没有实际收益的数据库。

## 便携卷宗

新版“洞天卷宗”可逐份导出存档。导出文件包含：

- 明确的《问道长生》便携卷宗格式和格式版本；
- 原卷宗名称、游戏版本、规则文档指纹与导出时间；
- 完整结构化游戏状态；
- 对规范化状态计算的 SHA-256 内容校验值。

导出不改变当前世界，也不会把 `.env`、API 密钥、其他存档或本机路径写入文件。

## 安全导入

卷宗界面可以直接选择 JSON 文件导入：

- 便携卷宗必须通过格式、版本、SHA-256、状态结构、历法范围和规则指纹校验；
- 兼容从旧游戏目录复制出的原始 `data/saves/*.json`；
- 单份文件限制为 2 MB，接口也会在解析前拦截超限请求；
- 同名文件默认保存为“原名_导入1”等新名称，不静默覆盖；
- 导入只增加一份可选卷宗，不会自动替换当前正在游玩的世界；
- 玩家仍需在卷宗列表中二次点击确认读取。

只有内部接口显式传入覆盖选项时才会替换同名卷宗，替换前仍沿用现有 `.json.bak` 备份机制；新版界面不会默认使用该选项。

## 界面交互

每份已有卷宗现在同时提供“导出”和“读取”按钮。迁移区独立展示导入状态、错误原因和同名改名结果，不把技术 JSON 内容直接堆在主游戏界面。

V0.58 仍是 `main` 上的内部稳定版本，不创建标签或 Release。正式玩家验收通过后统一升为 `v1.0.0`。

正式候选包的全新解压冒烟测试也会现场生成自动存档、导出便携卷宗并以同名冲突方式重新导入，确认最终 ZIP 中的接口与仓库测试保持一致。
