# V0.32 新版全流程迁移说明

V0.32 的目标不是继续堆叠通用文字卡，而是让主要玩法拥有适合自己的视觉与交互结构，同时确保所有操作仍由同一套 Python 规则引擎真实结算。

## 本版完成

- 坊市：分类货架、买卖价格、持有数量、余额和禁用状态。
- 洞府：设施等级、升级成本、材料门槛、灵田种植与收获。
- 技艺：丹、器、符配方，材料、产物、成功率与制作入口。
- 宗门：宗门身份卡、门派特色和入门试炼入口。
- 秘境与地图：真实境界准入、危险标签和对应行动。
- 存读档：命名保存、已有卷宗摘要、二次确认读取与覆盖备份。
- 操作反馈：成功提示与服务端错误提示。
- 成果巡览：12 个由隔离规则引擎生成的真实页面状态。

## 安全边界

成果巡览会为每一页创建独立的临时规则引擎和临时存档目录。它不会调用正式游戏实例的行动接口，也不会读写 `data/saves`。自动测试同样将存档路径改到临时目录，并核对正式自动存档哈希不变。

## 技术边界

React 只负责界面状态、弹窗、提示与页面呈现；FastAPI 只提供本地版本化接口；Python 规则引擎仍是数值、概率、时间、战斗和存档的唯一权威来源。V0.30 原生网页继续保留为兼容入口。
