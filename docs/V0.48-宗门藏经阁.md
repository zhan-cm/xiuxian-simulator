# V0.48 宗门藏经阁

V0.48 为既有宗门任务、晋升、大比和护宗战补上长期消费出口。宗门贡献不再只是越积越多的晋升数字，而能换取各宗专属功法、法术、丹药、法宝与高阶资源。

## 三宗传承

- 青云宗：长生青简、缚灵秘录、青岳灵珠与云海道痕，侧重养生、控场、阵法与悟道。
- 丹霞谷：丹霞火经、回春丹匣、结丹灵药与丹火道痕，侧重丹火、续航和破境资源。
- 玄剑门：庚金剑气录、玄铁剑胚、太虚剑典与五行剑丸，侧重直接攻伐、法宝与剑道构筑。

供奉按外门、内门、真传和长老权限逐层开放。兑换会真实扣除宗门贡献、写入乾坤袋和持久化领取记录；同一供奉本世不可重复领取。如果玩家已经掌握对应功法或法术，系统会阻止重复兑换。

## 年度传功

每个自然年可接受一次宗门长老讲法，消耗 60 宗门贡献并推进一个月。传功稳定增加感悟与修为，收益随当前职位提升；记录按年份与宗门保存，换年后才会重新开放。

## 界面与兼容性

加入宗门后，主界面会出现“宗门藏经阁”卷宗入口。弹窗固定显示当前身份、贡献、可领取数量和五阶权限路径，只有供奉列表区域滚动；桌面为双栏，手机自动切为单栏。

成果巡览新增第 28 页“宗门藏经阁”，使用青云宗真传样例进行只读验收。V0.47 及更早存档缺少 `sect_library_claims`、`sect_guidance_records` 或 `sect_library_history` 时会自动采用安全默认值。
