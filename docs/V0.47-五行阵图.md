# V0.47 五行阵图

V0.47 将原始《问道长生》规则中的阵法、结界、困敌和聚灵补成可长期培养、装配与维护的正式系统。阵盘不是静态收藏：聚灵阵会影响修炼结算，战斗阵法会改变当前回合，并持续消耗阵基。

## 五卷阵图

- 赤阳焚敌阵：炼气可学的火行杀阵，催动后造成阵法伤害。
- 玄土结界阵：炼气可学的土行结界，兼具本轮减伤与敌方压制。
- 缚风困灵阵：筑基开放的木行困阵，压低敌势并令下一击必中。
- 青木聚灵阵：筑基开放的聚灵阵，装配后提高修炼收益，临阵催动可回灵。
- 五行轮转阵：结晶开放的万象阵，按五行生克发动高额阵法伤害。

炼制成功率由阵图基础、神识、阵法技艺、洞府聚灵阵和阵道层数共同决定。炼制无论成败都会消耗阵材并推进一个月；每两次成功炼制可提高一级阵法技艺。

## 阵盘与战斗

玩家可在非抉择阶段自由切换已炼成阵盘，切换本身不推进时间。每场战斗只能催动一次阵盘，系统会校验灵力、阵基与当前装配状态；催动后的伤害、减伤、控场或回灵会进入既有战斗状态机，不以叙事文本代替结算。

阵盘完整度上限为 100。阵道可同时降低灵力与阵基消耗；阵基不足时战斗按钮会提前禁用并说明原因。修复消耗灵铁×1、恢复最多 35 点阵基并推进一个月。

## 界面与兼容性

新版“五行阵图”卷宗采用独立阵盘卡、五行与定位标记、阵材/成功率小组件、阵基仪表和上下文操作按钮。只有阵图列表区域滚动，标题与总览保持可见；桌面为双栏，窄屏自动切为单栏。

成果巡览新增第 27 页“五行阵图”，预置三卷不同完整度的阵盘用于只读验收。旧存档缺少 `formation_arrays`、`active_formation` 或 `formation_history` 时会自动采用安全默认值。
