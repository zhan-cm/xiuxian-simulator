# V0.33 道途章程

V0.33 为已有的修炼、探索、洞府、技艺、关系、宗门、战斗、秘境、突破与天下系统增加一条可理解的长期成长脉络。它不是线性主线，也不会替玩家选择，只负责记录已经真实发生的修行足迹并提供阶段奖励。

## 四章结构

1. 初涉仙途：初次吐纳、踏访青岳、获得首份资源。
2. 立足东洲：经营洞府、修习百艺、结识人物，并在宗门或散修声望中任选一条立身路线。
3. 名动一州：完成筑基、斗法获胜、进入秘境并积累声望或贡献。
4. 执掌因果：踏入金丹、建立深层关系、干预天下并让技艺或洞府登堂入室。

## 状态与奖励

目标完成情况由 `GameState` 中的境界、资源、设施、技艺、关系、历史和世界状态实时推导。已领取目标、累计历练与必须显式记录的战斗胜利计数会写入 JSON 存档。每份奖励只能领取一次，读取旧存档时新增字段会采用安全默认值。

## 界面原则

主页面只增加一条紧凑进度带。玩家点击后才展开完整四章；进行中、可领取、已领取和锁定状态共享统一组件。成果巡览使用隔离规则引擎生成 2/3 完成的示例，并禁用所有领取操作。
