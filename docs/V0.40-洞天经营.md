# V0.40 洞天经营

V0.40 将已有洞府设施从一次性升级菜单扩展为会随九州时间持续运转的经营系统。规则继续以原始文案中的洞府灵气、静室、丹房、器坊、灵田、聚灵阵与禁制为边界，不引入数据库，也不把材料和收益交给叙事模型计算。

## 长期运转

- 洞府每月积累灵蕴，容量和产量由聚灵阵、禁制及当前方针共同决定。
- 蕴养灵脉提高灵蕴产量；潜修养元消耗灵蕴增长修为；灵田轮作加快已有作物成熟；百艺轮转提高后台生产成功率。
- 切换方针本身不推进月份，但从下一次真实时间推进开始生效。

## 后台工坊

- 丹房、器坊和静室分别承载对应配方，设施等级就是该设施的并行生产位数量。
- 安排任务时立即验证设施、容量与材料，并把投入材料从乾坤袋中预留。
- 生产任务会在修炼、游历、交易或其他真实月度行动中自然推进，不要求玩家停在洞府页面等待。
- 到期后由存档随机种子稳定判定成败；成功增加产物与技艺经验，失败损失预留材料。
- 任务未完成前可取消，全部预留材料原样返还，不推进游戏时间。

## 界面与存档

- 洞府页将灵蕴、方针、后台工坊、设施、配方、灵田与最近月报拆成层级明确的小组件。
- 配方和设施说明按需折叠，避免重新形成大段文字清单；窄屏下方针、任务和配方自动切为单列。
- 新增状态全部进入原有 JSON 存档，V0.39 及更早存档会获得安全默认值。
- 成果巡览使用隔离规则引擎创建真实在制任务，不触碰正式自动存档。
