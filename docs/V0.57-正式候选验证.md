# V0.57 正式候选验证

V0.57 补齐正式发布包的独立验证与全新解压端到端验收。本版仍是 `main` 上的内部稳定版本，不创建标签或 Release。

## 发布包验证

新增 `scripts/verify_release.py`：

- 对照同名 `.sha256` 文件验证下载内容，文件名和摘要必须同时匹配；
- 检查 ZIP 顶层目录与语义版本，拒绝重复路径、路径穿越、盘符路径和符号链接；
- 限制异常解压体积，并使用 ZIP CRC 检查损坏内容；
- 再次核对必需文件，拒绝真实 `.env`、私人存档、测试目录、依赖缓存和开发产物。

## 全新目录冒烟测试

传入 `--smoke` 后，验证器会把发布包解压到一次性临时目录，并依次验证：

1. `main.py --check` 环境自检；
2. React 生产页面可以读取；
3. 本地健康接口与初始状态可以访问；
4. “开始游戏”可以真实推进到创角阶段；
5. 34 页成果巡览可以从隔离规则引擎生成。

临时目录会在验收后自动清理，不接触玩家的正式存档。

## 使用方式

    python scripts/package_release.py
    python scripts/verify_release.py --smoke

验证其他路径或正式版包：

    python scripts/verify_release.py C:\下载\Wendao-Changsheng-v1.0.0-windows.zip --expected-version 1.0.0 --smoke

GitHub 持续集成会在每次推送时实际生成内部发布包并执行上述完整流程，不再只检查文件清单。

## Windows 首启兼容

新版启动器创建专用环境时会依次检查 Windows `py` 启动器与 `python` 命令。只有其中一个可用且版本达到 Python 3.11，就能正常完成首次安装；不再出现环境检查通过、启动器却因缺少 `py.exe` 失败的矛盾情况。
