# V0.43 灵潮终章

V0.43 补完从 V0.35 起只开放前三章的“灵潮因果”主线。主线现在拥有上下两卷、六个章节、三条贯穿因果倾向和三种可持久保存的阶段性结局。

## 下卷三章

### 第四章：魔潮越界

古印余波越过东洲，南疆火脉化作魔潮。完成第三章并实际踏访至少两域后解锁。

- **守城安民**：损失气血，换取功德、南疆民生与局势缓和。
- **深入魔隙**：承担伤势与业力，取得魔髓晶核和道韵。
- **联络五域**：提升玩家及五域声望，推动四方势力共同应对。

### 第五章：九州会盟

玩家完成第四章并亲自抵达中州后，才能参加天阙台会盟。

- **共筑天幕**：真实消耗 200 灵石，改善五域民生并压低天下局势。
- **独探天隙**：以气血换取道韵与道心，同时承担局势恶化。
- **缔结九州盟誓**：以个人声望凝聚四方势力。

### 第六章：潮汐终局

完成会盟并踏入结晶境后，登仙台显现三条终局路线：镇世封天、叩问天门与万宗共潮。

## 因果倾向

前五章的每一项选择分别归入：

- **守世**：重视山河、生民、封印和稳固秩序。
- **问天**：追索真相、力量、天门与飞升旧路。
- **同道**：联合宗门、地方势力与九州众生共同应对。

倾向不是额外任务，也不限制终章选择。终章仍由玩家亲自决定；与所选结局相同的前置倾向达到三次时，结局进入“因果相契”，达到四至五次时进入“道途圆满”，获得更强但仍可解释的永久回报。

旧存档不需要新建倾向字段。规则引擎会从既有 `story_choices` 自动重算，因此不会出现两套互相失去同步的进度。

## 三种本世结局

### 人间长明

镇世封天，将灵潮引回九州山河。降低天下局势，提高功德与五域民生；圆满时进一步强化气血根基，获得命格“九州守望”，世界进入“灵潮新世”。

### 天门初开

亲自踏入断裂天门，追问飞升真相。提高道韵、神识与道心，但会让九州继续承担天门开启带来的局势压力；获得命格“天门见证”，世界进入“天门初开”。

### 九州同盟

让五域与万宗共同承接灵潮。提升个人与地方声望、四方势力和天下稳定，获得命格“万宗执盟”，世界进入“九州盟世”。

每个结局保存标题、路线、共鸣、完成度、结语、命格、年份与回合，并写入世界里程碑。它是当前灵潮篇章的阶段性终点，不会强制结束角色后续修炼和自由行动。

## 界面与兼容

- 灵潮因果录拆为“上卷·东洲潮声”和“下卷·九州终局”，每卷三张章节卡。
- 新增守世、问天、同道三项紧凑共鸣仪表，突出占优路线但不把其他选择隐藏。
- 终章抉择按钮展示当前路线共鸣和预计完成度。
- 资源不足的主线选择会提前禁用并说明原因。
- 终章落定后显示独立结局卡，同时保留六章选择与历史回顾。
- V0.42 及更早存档缺少 `story_ending` 时使用空结局默认值。
- 成果巡览新增“潮汐终局”和“本世结局”两页，均使用隔离存档。
