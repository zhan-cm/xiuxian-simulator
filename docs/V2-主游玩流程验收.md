# V2 主游玩流程验收

本批工作对应开发蓝图阶段二。开发分支为 `codex/immersive-ui`，本地生产页面已随代码重建。稳定版与正式 Release 仍为 v1.0.0。

## 1. 打开页面

在项目目录双击 `启动新版界面.bat`。如果游戏已经开着，刷新页面；浏览器仍显示旧样式时使用 Ctrl+F5。

先使用右上角「成果巡览」检验界面。这一模式使用隔离示例，不会修改正在玩的存档；进行实际游玩操作前，退出巡览并在「洞天卷宗」中保存当前进度。

## 2. 场景与剧情

1. 查看顶部气血、灵力、修为，确认数字和主角一致。
2. 场景中查看地点、事件标题及合并后的回合与历法。
3. 短叙事应完整显示，不应出现为了填满卡片而设置的固定空白。
4. 首段超过 120 字时点击「读完这段」，确认能读到末尾。长文弹窗只滚动正文，关闭后回到阅读入口。
5. 查看探索、修炼或战斗的结算：前三项变化在场景内显示，余项在下方显示；每项只出现一次。

场景配色会根据斗法、坊市、宗门、探索、洞府修炼切换，目前山水和角色形象是占位表现，最终背景与立绘尚未接入。

## 3. 洞天侧记与原有功能

点击底部「洞天侧记」，按以下分类查看：

| 分类 | 功能入口 |
|---|---|
| 修士与行囊 | 修士名帖、道途根基、伤势详情、乾坤袋 |
| 修行百艺 · 仙途与因果 | 灵潮主线、道途章程、东洲悬榜 |
| 修行百艺 · 修行与百艺 | 悟道、百艺、灵兽、阵法、法器 |
| 修行百艺 · 山门事务 | 藏经阁、开宗立派与宗门经营 |
| 修行百艺 · 九州机缘 | 正在开放的拍卖会、新世卷宗；未触发时不占位 |
| 尘世见闻 | 人物牵绊、最近经历、九州风声、众生缘网入口 |

检验重点：

- 主场景前方不再堆叠上述十多个系统入口。
- 分类切换只影响显示，不推进时间。
- 点击百艺入口会打开对应详情；关闭详情后仍回到原分类。
- 在侧记内执行有效行动后，侧记收起，回到主场景查看结果。
- Esc 关闭侧记，键盘焦点返回底部入口。按 Tab 不应进入遮罩后的页面。
- 主线可推进、新世事件可处理、委托可交付时，入口有金色提醒点。此点表示当前有可办理事项，并非未读消息。

## 4. 行动与只读限制

1. 地图与坊市通过底栏进入；一键行动区保留修炼、闭关和存档，减少重复入口。
2. 出现实际伤势时，快捷区增加「静养疗伤」，是否可点击及行动内容由规则返回。
3. 没有伤势时，快捷区按真实状态只突出一项情境行动：修为圆满优先提示突破，其后依次为新世余波、可推进主线、可交付委托和当前地域机缘；提示不会绕过规则直接结算。
4. 点击行动草稿只填入输入框；修改后点击「推演此行」才执行。
5. 创角、战斗、突破等阶段先完成对应抉择，普通导航应置灰并解释原因；仍可打开侧记查看已有资料。
6. 人情纷争等允许暂缓的事项仍遵循原规则，不会仅因展示为抉择就强行锁住其他行动。
7. 成果巡览中，场景数据卡片、一键行动、草稿提交均不能改变游戏；返回游玩后，原本未提交的草稿仍在。

## 5. 人物会面

在成果巡览中打开「松间相叙」，确认：

- 玩家与顾清玄分列叙事两侧，NPC 姓名、身份、状态、关系和好感不再挤成一行。
- 人物气氛会依据亲近、戒备、负伤、论道与赠礼状态变化。
- 「继续交谈」「论道印证」会执行规则引擎已有行动。
- 礼物选择只列出乾坤袋中实际持有的礼物，送出时使用当前人物和选定物品。
- 好感达到门槛后显示结契入口；已经结为道侣后显示合修入口。
- 「浮生故人」首先呈现低文字密度的人物画廊：人物形象、身份、境界、年岁、关系和好感拆成独立小组件，不再堆成长句。
- 从人物画廊可打开独立人物档案，集中查看身份、寿元、所在地、喜好与近世行迹；返回游玩后可继续交谈或论道。
- 成果巡览允许打开人物档案，但交谈、论道与护道按钮保持禁用，不会修改正式存档。

当前人物造型仍为代码绘制的国风占位立绘，正式人物美术将在阶段六统一接入。

## 6. 地图、坊市、宗门与洞府

在「成果巡览」中依次打开地图、九州舆图、坊市、宗门与洞府页面，确认：

- 各页面均有独立的墨绿场景题头，以「游、州、市、宗、府」印记快速识别当前系统；题头下的数据仍来自原规则引擎。
- 探索地点以风险色、四段风险尺和准入标签共同表达危险度；未达境界的路线置灰，并直接显示解锁条件。
- 九州舆图以卷轴地图呈现五域方位，点击地域节点只切换右侧路线详情；不会再同时铺开五张大卡片。
- 地域节点与详情区明确区分当前落脚、已踏访与未解锁状态；当前地域若存在尚未处理的真实地方事件，会显示「有地方机缘」或「机缘待决」，已经完成后自动消失。
- 坊市按货物类别筛选；点击左侧货架会在详情区显示品级、来历、实际用途、库存与行情，买入和卖出按钮根据灵石及库存自动置灰。
- 成果巡览中仍可切换货架分类、选择物品和查看详情，但买卖、探索、旅行、洞府生产与宗门试炼等会改变状态的按钮全部禁用。
- 宗门选择以山门卡展示道统气质，申请试炼仍按原规则推进；洞府方针、灵蕴、工坊和设施升级具有一致的悬浮、激活及禁用反馈。
- 地点或货架数量增加时，只滚动卡片列表，系统题头和说明保持可见。

这些页面采用同一套组件层级，但不使用同一张通用卡片简单换字，避免再次出现功能辨识度不足的问题。

## 7. 小屏幕检查

缩窄窗口至约 390 像素宽，确认：

- 「成果巡览」「洞天卷宗」「道途详览」入口仍能找到。
- 场景的人物与叙事上下排列，正文不会覆盖人物；长文字可使场景自然增高。
- 侧记标题和分类保持可见，只有内容区域滚动。
- 巡览导航与底部世界导航不互相盖住。
- 气血等状态、抉择和关闭按钮均可点击，页面无横向溢出。

## 8. 本批自动检查范围与尚待确认

组件检查覆盖长叙事完整性、结算去重、侧记分类、Esc 焦点返回、嵌套详情返回、草稿提交、情境快捷行动、巡览只读、导航禁用、人物画廊/档案，以及地图节点选择/风险/准入/事件标记和坊市筛选/详情/买卖状态；同时运行全量规则回归、生产构建与独立解压包冒烟检查。

自动检查可以验证结构与行为，不能证明实际画面美观。本批仍需玩家在实际窗口中确认字体、双角色场景比例、遮挡与阅读舒适度；正式 NPC 立绘与后续独立系统页面不在本批完成范围。
