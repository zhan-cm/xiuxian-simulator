# V0.61 单一新版入口

V0.61 删除已经完成历史迁移使命的 V0.30 原生网页，只保留 React + FastAPI 游戏界面。玩家不再需要判断“启动网页版”和“启动新版界面”之间的区别。

## 删除内容

- 删除根目录 `启动网页版.bat`；
- 删除 `web/` 下的旧 HTML、CSS 与 JavaScript；
- 删除命令行 `--web` 参数和标准库 HTTP 服务；
- 发布包不再收录旧启动器或旧静态资源；
- 环境自检不再要求已经废弃的页面文件存在。

## 保留内容

- `启动新版界面.bat` 是唯一图形界面入口；
- `检查环境.bat` 继续负责启动诊断和故障留痕；
- Python 规则引擎、JSON 存档和全部旧存档迁移逻辑不变；
- 命令行模式仍可直接运行，便于排障与开发；
- React 页面、FastAPI 接口、成果巡览和便携卷宗保持完整。

## 后端收敛

共享应用层不再承担旧静态文件分发与旧版 HTTP 路由，只负责生成结构化快照、执行行动和迁移存档。新版 FastAPI 成为唯一网页服务边界，减少重复路由、安全配置和测试维护成本。

本版仍只提交到 `main`，不创建内部标签或 Release。玩家验收完成后统一发布 `v1.0.0`“《问道长生》正式版”。
