# V0.55 正式版整备

V0.55 不扩张玩法边界，而是把已完成的规则、界面与仓库整理到可正式发布的状态。本版仍是内部开发版本，不创建标签或 GitHub Release。

## 持续集成

公开仓库新增 Windows 持续集成。每次推送到 main 或提交合并请求时，会分别验证：

- Python 3.12 下安装项目与开发依赖；
- 规则引擎全量回归和发布树启动自检；
- Node.js 22 下锁定安装前端依赖；
- 前端静态检查、组件测试和生产构建；
- 仓库内预构建资源与源码是否保持同步。

工作流只申请仓库只读权限，不创建标签、发布或其他外部状态。

## 生产资源

Vite 8 构建改为按职责拆分 React 核心、界面组件、状态数据与游戏代码。浏览器可分别缓存稳定依赖，主游戏脚本不再超过单块警告阈值。构建同时生成 third-party-licenses.md，保留所有前端依赖的许可文本。

## 玩家入口

首次游玩指南改以 启动新版界面.bat 为推荐入口，明确成果巡览不会修改存档，并区分一键行动与可编辑行动草稿。旧版入口继续作为兼容后备，不会被删除。

## 发布约束

内部 V0.x 版本只在 main 留下稳定提交，不再创建零散标签或 Release。正式发布必须逐项通过 docs/正式发布检查清单.md，随后才将版本号统一提升为 1.0.0，创建单个 v1.0.0 标签与正式 Release。
