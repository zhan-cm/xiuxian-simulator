# V0.51 伤势与疗愈

V0.51 将过去散落在战斗、秘境、行旅与突破文本中的“重伤”收束为一套可持续游玩的恢复循环。失败仍然可能致死；侥幸生还也不再能立刻当作无事发生。

## 四类伤势

| 伤势 | 常见来源 | 主要影响 |
| --- | --- | --- |
| 筋骨外伤 | 斗法、行旅、秘境、宗门任务 | 攻势、遁速与承伤 |
| 经脉受损 | 灵力反噬、低阶破境失败 | 吐纳、施法与遁速 |
| 心魔侵蚀 | 心魔劫、道心失守 | 吐纳、斗法与后续破境 |
| 道基暗伤 | 高境界破境失败 | 全面而长期的数值压制 |

每类伤势分为轻微、沉重、危重三级。调养期和惩罚由类型与严重度共同决定，多种伤势同时存在时会叠加，但系统设置了安全下限，避免角色因数值相乘而彻底失去行动能力。

## 疗愈循环

- 每推进一个月，所有持续伤势的调养期自然减少一个月。
- 输入“静养”会推进一个月，恢复气血、灵力并额外缩短最严重伤势的调养期。
- 使用疗伤丹会恢复气血，并将最严重伤势的调养期缩短三个月；即使气血已满，只要仍有持续伤势，丹药仍可使用。
- 洞府调息会继承静室等级作为治疗加成，并继续使用既有灵蕴消耗与月度生产规则。
- 持续伤势存在时禁止大境界突破，痊愈后自动恢复资格。

## 兼容与存档

新增的 `injuries` 与 `injury_history` 字段由旧存档安全使用空默认值。若旧档角色状态仍包含“重伤”“反噬”“心魔”或“暗伤”等文字，界面快照会先只读推断；首次自然恢复或治疗时再正式迁入结构化记录，不会因为查看面板而偷偷改写存档。

## 界面

健康角色仍保持原有紧凑根基面板。负伤后才出现伤势警示入口，打开后可查看：

- 当前气血与灵力；
- 每一处伤势的来源、严重度和剩余月份；
- 吐纳、攻势、承伤和遁速的汇总变化；
- 静养与疗伤丹的真实可用状态；
- 最近八条受伤和疗愈记录。

成果巡览增加独立“伤势疗愈”页面，使用隔离状态展示双重伤势和疗愈按钮，所有操作在巡览模式中保持只读。
