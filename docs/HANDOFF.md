## 二、新设备极速部署开箱（约 3 分钟）

在全新电脑上拉取工程后，按以下步骤初始化环境：

### 1. 克隆代码仓库
```bash
git clone https://github.com/zhan-cm/xiuxian-simulator.git
cd xiuxian-simulator
git checkout main
```

### 2. 初始化 Python 后端环境
```powershell
# 建议 Python 3.11 或 3.12
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install --upgrade pip
.\.venv\Scripts\pip install -e .[dev]
```

### 3. 初始化前端依赖与构建
```powershell
cd frontend
npm install
npm run build
cd ..
```

### 4. 验证全栈测试基准（确保 100% 绿灯）
```powershell
# 1. 前端 Vitest 75 项测试
npm --prefix frontend test -- --run

# 2. 前端生产打包
npm --prefix frontend run build

# 3. 后端 Pytest 301 项测试
.\.venv\Scripts\python.exe -m pytest

# 4. 发布资产完整性校验
.\.venv\Scripts\python.exe scripts\package_release.py --check
```

### 5. 一键启动游戏
- Windows 下直接双击根目录 `启动游戏.bat`（或 `start_game.bat`）即可同时启动前后端并呼出沉浸式桌面客户端。
