# V0.36 乾坤万象

V0.36 将乾坤袋从名称与数量预览升级为连接探索、交易、百艺、战斗和养成的正式物品系统。所有效果仍由 Python 规则引擎结算，React 只负责分类、详情和操作呈现。

## 规则闭环

- 统一物品图鉴记录分类、品级、描述、用途与可执行动作，旧存档中的未知物品会安全归入“其他”。
- 聚气丹增加当前境界修为；疗伤丹与灵食恢复气血或灵力，状态已满时拒绝消耗。
- 武器与护甲可直接装备或卸下，槽位与既有道法、战斗公式完全共用。
- 符箓、破境资源、材料、奇珍与礼物明确说明使用场景，不把“查看详情”伪装成可执行动作。
- 物品使用和装备变化立即写入自动存档，不额外推进月份。

## 界面

- 左侧乾坤袋保持四件紧凑预览，避免压缩主游戏区域。
- 完整弹窗提供分类标签、藏品清单、品级标识、详情说明、持有数量、装备状态和武器/护甲槽。
- 桌面采用藏品与详情双栏，手机自动改为单栏；只有清单区域在内容溢出时滚动。
- 成果巡览增加“乾坤万象”页面，全部操作在只读模式下禁用。

## 验收重点

1. 使用丹药后状态与数量同时变化，并写入存档。
2. 满气血或满灵力时不会浪费恢复物品。
3. 装备、卸下和出售最后一件法宝后，槽位状态始终一致。
4. V0.35 及更早存档无需迁移脚本即可打开。
