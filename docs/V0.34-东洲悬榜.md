# V0.34 东洲悬榜

V0.34 将已有探索、斗法、百艺、宗门、坊市、修炼与物资系统串成一套可重复游玩的短期目标循环。悬榜只记录玩家亲自完成的行动，不会替玩家选择宗门、关系或突破路线。

## 轮换与追踪

- 东洲悬榜每三个月轮换一次，每期从七类模板中稳定展示四份委托。
- 同时最多追踪两份；当期已经完成的委托不能重复接取或领奖。
- 每份委托都有独立期限。跨月行动结束后若超过期限，委托会自动撤下并记录逾期。
- 主界面只显示紧凑入口，完整任务簿通过无障碍弹窗展开。

## 真实进度

- 物资交付：按乾坤袋当前持有量判断，交付时真实扣除材料。
- 探索、斗法、百艺、宗门、坊市和修炼：接取时记录计数基线，只统计接取后发生的新行动。
- 报酬由本地规则引擎发放，可包含灵石、声望、功德与修行资源。
- 委托信誉、在途记录、完成编号和最近委托历史全部写入 JSON 存档；旧存档采用安全默认值。

## 界面与验收

任务簿把在途委托与本期悬榜分开呈现，直接展示委托人、类型、要求、限期、报酬、进度以及禁用原因。桌面使用双列卡片，窄屏自动改成单列。成果巡览新增第十四页，并强制禁用所有会修改存档的操作。
