# 《问道长生》正式版

《问道长生》是一款本地运行、规则驱动的高自由修仙文字模拟器。游戏以原始《修仙模拟器 · 问道长生》规则文案为根基，将创角、修炼、突破、战斗、秘境、坊市、宗门、情缘、洞府、五域行旅、灵潮主线、开宗立派与轮回传承整合为同一套持续演化的单机世界。

## 正式版内容

- 结构化创角、境界修炼、大小突破、心魔劫与雷劫；
- 五域地图、地方声望、动态坊市、限时拍卖、秘境与循环委托；
- 功法法术、法宝装备、炼丹炼器制符、阵法、灵兽与洞天经营；
- 六位核心人物的关系、寿元、修行、护道、缘网、情劫与故人记录；
- 宗门入门、职位晋升、藏经阁、大比、宗门战争、开宗立派、外交与护宗战；
- 六章灵潮主线、三条终局、新世余波、本世评传与有限轮回传承；
- 现代国风 React 界面、34 页成果巡览、完整存读档与兼容稳定界面；
- 可选 OpenAI 叙事润色；所有数值和状态仍由本地规则引擎结算。

## Windows 安装与启动

1. 下载 `Wendao-Changsheng-v1.0.0-windows.zip` 与同名 `.zip.sha256` 文件。
2. 将 ZIP 完整解压到普通文件夹，不要直接在压缩包预览窗口中启动。
3. 安装 Python 3.11 或更高版本，并确保 `py` 或 `python` 至少有一个命令行入口可用。
4. 双击 `启动新版界面.bat`。首次启动会创建项目专用环境并安装本地接口依赖。
5. 浏览器自动打开后即可开始游戏；关闭启动窗口会停止本地服务。

启动异常时先双击 `检查环境.bat`。若新版界面暂时无法启动，可使用 `启动网页版.bat` 进入兼容稳定界面。

## 完整性校验

已安装项目依赖后，可在解压目录执行：

    python scripts/verify_release.py C:\下载\Wendao-Changsheng-v1.0.0-windows.zip --expected-version 1.0.0 --smoke

验证器会核对 SHA-256、压缩包结构与私人数据边界，并在临时目录实际启动新版页面和本地接口。

## 存档与隐私

- 存档保存在解压目录的 `data/saves`，建议升级前备份该目录；
- 默认完全离线运行，不要求账号，也不会上传原始文档或存档；
- OpenAI 叙事是可选能力，只有玩家主动配置本机 `.env` 和自己的 API 密钥后才会联网；
- 发布包不包含开发者或其他玩家的存档、密钥、虚拟环境与依赖缓存。

## 已知限制

- 正式交付与自动验收以 Windows 10/11 为主，其他系统需要手动使用 Python 启动；
- 首次启动新版界面需要联网安装 Python 接口依赖，之后可以离线游玩；
- 游戏是本地单机作品，暂不提供多人联机、云存档或自动在线更新；
- 自由行动的叙事表现取决于所选叙事器，离线叙事会优先保证规则正确与可继续游玩。

## 发布约定

正式版本只创建一个 `v1.0.0` 标签，Release 名称为“《问道长生》正式版”。此前 V0.x 均为仓库内部迭代记录，不再拆分为多个公开 Release。
