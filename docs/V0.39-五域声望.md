# V0.39 五域声望与地方机缘

V0.39 让 V0.38 的五域行旅从“能够抵达”进入“地方会记住玩家”的阶段。东洲、南疆、西漠、北原与中州分别保存独立声望，并将玩家在当地的选择、探索和交易转化为长期待遇。

## 核心闭环

- 初次抵达异域会获得少量地方声望，并触发该地域唯一的地方机缘。
- 每项机缘提供三种不可替代的应对，资源门槛与结果在选择前完整展示。
- 声望分为声名狼藉、遭人戒备、初来乍到、略有薄名、受人敬重和名动一方六档。
- 正面声望降低当地买价、提高卖价，并增加探索与行旅判定；负面声望会产生相反影响。
- 每两次当地探索获得一点声望；累计交易额跨过门槛也会提升地方评价，单次交易最多提升两点，避免昂贵商品刷满声望。
- 五域声望、交易量、探索次数、地方机缘选择与历史全部进入 JSON 存档，旧档使用安全默认值。

## 五项地方机缘

- 东洲《青岳灵泉之争》
- 南疆《赤炎兽潮》
- 西漠《流沙古碑》
- 北原《寒渊断粮》
- 中州《天阙问名》

新版九州卡片直接显示地方评价和声望数值，坊市行情区显示当前地方待遇；成果巡览新增独立地方机缘页面，所有按钮保持只读。
