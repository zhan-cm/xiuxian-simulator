# 《永恒之道》后续项目推进与架构升级总方案
### 独立桌面应用软件化 · 纯正文字修仙深度打磨 · 东方美学前端重塑

> **定位**：高自由度、纯文字深度模拟、规则驱动的独立单机修仙桌面应用（Windows 客户端）。  
> **核心体验**：以东方美学长卷为皮相，以硬核寿元与五行生克为骨骼，以跌宕起伏的因果与前世遗冢为灵魂。

---

## 一、 产品形态定义：从“网页脚本”蜕变为“独立桌面软件”

### 1.1 终极交付形态
* **无控制台黑框**：彻底摒弃双击 `.bat` 弹出 cmd 黑窗口的开发阶段遗留体验；
* **无浏览器套壳感**：无 URL 地址栏、无标签页、无浏览器插件栏，拥有独立的《永恒之道》桌面图标与任务栏图标；
* **原生视窗体验**：
  * 支持 16:9 黄金比例默认分辨率（如 `1366 × 768` 或 `1280 × 800`，居中启动）；
  * 支持一键全屏（F11）、最小化与退出；
  * 窗口关闭时自动静默保存最新进度，优雅退出后台服务。

### 1.2 桌面化工程落地路线（PyWebView + PyInstaller）
* **原理**：利用 Python 驱动 Windows 原生自带的 Edge WebView2 渲染层，直接装载前端预构建包（`frontend/dist`），不依赖任何额外臃肿组件；
* **体积控制**：打包后体积维持在 30MB~50MB 的极其轻量水平，玩家解压即玩；
* **零重写保障**：100% 沿用已通过 273 项测试的 Python 领域规则引擎与 React 业务逻辑。

---

## 二、 前端界面重构设计方针：告别仪表盘，重铸仙侠长卷

### 2.1 当前界面痛点诊断
1. **“伪 2D 场景”的廉价感**：使用简单的 CSS 拼贴几何山丘和小太阳，既无法达到商业 2D 游戏的精美，又严重破坏了文字修仙应有的庄严古典意境；
2. **“管理系统式布局”**：三栏卡片、大量信息密集堆叠，宛如企业后台管理系统或工单仪表盘，缺乏游戏氛围；
3. **“文字叙事反被边缘化”**：文字是修仙模拟的核心，但此前被压缩在一个小角落，甚至需反复点击“读完这段”弹窗，割裂了修真岁月的代入感。

### 2.2 全新 UI 设计哲学：“东方留白 · 水墨玄境 · 古卷沉浸”
* **基调配色**：松烟玄墨（`#121619`）为底，古朴暗宣（`#1C2226` / `#2A3238`）为面，点缀青碧灵玉（`#4E9A86`）、紫霄神雷（`#8A6FA8`）、朱砂赤血（`#C0584F`）与鎏金古印（`#C9A050`）；
* **三大核心视窗布局**：
  1. **天命命牌（左侧 / 顶部）**：
     * 寿元生死沙漏/环形天轮（大限倒计时可视化，压迫感油然而生）；
     * 境界尊号、主修功法与五行生克罗盘；
     * 气血（朱砂）、灵力（玄青）、神识（紫薇）灵脉条；
  2. **万古长卷（中央主舞台）**：
     * 摒弃低幼的 CSS 几何图形，改为**深邃流动的烟霭水墨意象**；
     * **叙事主体居中纵向流动**：岁月流转、事件发生、境界突破文字如古籍竹简徐徐展开，字体雅致文白相间；
     * **抉择玉牌**：重大分支以悬浮古雅玉牌呈现，带有“机缘”、“风险”、“魔道”等卦象印鉴，点击有金石玉碎般的清脆反馈；
     * **战斗神机台**：斗法时转化为敌我气场威压对峙台，五行元素反应（爆燃、感电打断、冰封）实时以符文法阵形式显现；
  3. **乾坤机枢（底部行动盘）**：
     * 犹如道家推演八卦盘，常驻核心行动（吐纳修炼、闭关破境、神念游历）；
     * 自由心念输入框设计为“心念一动”，支持玩家天马行空的自由指令。
