# V0.52 仙途评传与轮回传承

V0.52 补上从“本世死亡”到“下一世启程”的完整闭环。死亡仍然有真实代价，但已经投入的时间会沉淀为可回顾的生涯卷宗，并由玩家亲自决定唯一一道有限传承。

## 本世评传

任何既有死亡路径进入 `ended` 状态后，规则引擎都会集中生成一份本世评传。同一世只记录一次，重复查看不会重复增加卷宗或奖励。

评传保存：

- 姓名、道号、宗门、最终境界、寿数、落幕时间与原因；
- 道途评分和生涯位阶；
- 踏访地域、完成主线、尘缘人物、完成委托、悟道层数与灵兽同伴；
- 本命法宝、主线结局、道侣等本世重要留痕。

历世卷宗最多保存最近十二世，避免存档无边界膨胀。

## 轮回传承

本世落幕后会出现三道余痕，必须由玩家亲自铭刻一道，之后才能进入下一世创角：

| 传承 | 下一世一次性效果 |
|---|---|
| 百炼余骨 | 气血上限 +12，寿元 +6 |
| 宿慧道种 | 悟性 +2，道心 +1，初始感悟 +10 |
| 袖里余藏 | 初始灵石 +180，聚气丹 +2 |
| 九州余愿 | 声望 +8，五域声望 +5，悟道点 +1 |

“九州余愿”需要完成灵潮结局或推进至少四章主线才会替代“袖里余藏”进入候选。

传承只在紧接的下一世完成创角时应用一次。游玩中再次输入“开始游戏”不会重置本世，也不能重复领取传承。

## 新版界面

终局不再沿用普通事件卡，而切换为全宽评传页面：

- 顶部显示本世位阶和道途评分；
- 中部展示碑传、落幕原因、六项生涯指标和重要留痕；
- 下方三张传承卡明确区分可选、悬浮、已选和禁用状态；
- 未选择传承时，“启封下一世”保持锁定并说明原因；
- 成果巡览新增第 32 页“仙途评传”，可以在不修改正式存档的情况下完整检查终局页面。

## 兼容性

V0.51 及更早存档没有轮回字段时会自动采用安全默认值。旧版已经结束的存档在打开界面时可以生成只读评传快照；只有实际执行终局操作时才会写入存档。
