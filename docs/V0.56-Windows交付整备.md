# V0.56 Windows 交付整备

V0.56 为最终正式 Release 准备普通玩家可直接下载的 Windows ZIP，不新增玩法，也不创建内部标签或 Release。

## 发布清单

打包器只收录游戏运行与重新构建所需的明确目录：Python 规则引擎、两套网页界面、新版前端源码与预构建资源、结构化内容、原始规则文档、玩家指南和三个 Windows 批处理入口。

以下内容一定不会进入发布包：

- 本机虚拟环境和 Python 缓存；
- frontend/node_modules 与 npm 缓存；
- data/saves 中的 JSON 私人存档和备份；
- .env、大模型密钥和其他本机配置；
- Git 仓库数据、测试目录与历史构建产物。

## 可复现与防误覆盖

ZIP 内文件顺序、时间戳与权限字段固定，同一提交重复构建会得到相同 SHA-256。默认不覆盖已有成品，必须显式使用 --force 才能替换同名文件。

每个 ZIP 都会生成同名 .zip.sha256 文件。正式 Release 将同时上传两者，玩家可以核对下载完整性。

## 使用方式

仅检查清单：

    python scripts/package_release.py --check

构建内部验收包：

    python scripts/package_release.py

正式发布时：

    python scripts/package_release.py --version 1.0.0

GitHub 持续集成会在每次推送时执行清单检查；实际写出 ZIP 的步骤只在正式发布前人工执行，避免生成零散 Release。
