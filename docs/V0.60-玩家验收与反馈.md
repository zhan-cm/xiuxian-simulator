# V0.60 玩家验收与反馈

V0.60 将已有的 34 页“成果巡览”升级为正式版前的玩家验收工具。它仍然只展示隔离生成的代表状态，不会写入或覆盖真实存档。

## 逐页验收

- 每页可以独立标记“已检查”，顶部同时显示浏览位置与整体验收进度。
- 页面下拉列表会给已检查页面添加标记，便于发现遗漏。
- 每页可记录最多 600 个字符的问题或建议，适合记录窄屏遮挡、按钮失效、术语不清等具体问题。
- 当前页、勾选状态与备注保存在浏览器本地；暂时退出后再次进入，会自动回到上次检查的页面。

## 反馈摘要

“复制摘要”会生成一份可直接粘贴的文本，其中只包含：

- 当前应用版本；
- 已检查和待检查的页面；
- 玩家主动填写的页面备注。

摘要不会包含角色资料、游戏存档、API 密钥或玩家电脑路径。验收状态也不会进入 JSON 存档或便携卷宗。

## 版本隔离

应用版本和存档版本现在由接口分别提供。读取旧版存档时，存档仍保留其原始版本号，但玩家验收进度始终归属于当前运行的程序版本。升级到新版本后会开始一轮新的验收，避免沿用已经过时的页面结论。

## 发布约定

V0.60 只提交到公开仓库的 `main`，不创建标签或 GitHub Release。完成玩家视角验收并修正反馈后，项目统一升为 `v1.0.0`，Release 标题使用“《问道长生》正式版”。
