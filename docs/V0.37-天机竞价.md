# V0.37 天机竞价

V0.37 将原始规则中的“不定期天机拍卖会”从一条世界新闻升级为真实经济事件。拍卖仍完全由本地规则引擎结算，不依赖联网服务。

## 开放与期限

- 每月随九州时间线进行一次稳定随机判定，命中后开启一场持续两个月的临时拍卖。
- 同一存档、同一年月会生成相同的拍品与主要对手，方便回归测试与问题复现。
- 每场展示四件轮换拍品；超过期限后，未参与拍品自动归场外买家。
- 拍卖尚未结束时不会重复开启或反复发布公告。

## 竞价

- 每件拍品记录起拍价、加价幅度、所得物品和最低境界。
- 进入竞拍后必须选择稳健举牌、强势压场或退出竞价。
- 稳健举牌价格较低；强势压场一次抬高三档价格，但拥有更高成交机会。
- 成交概率由策略、仙缘、声望与主要对手压力共同计算，判定结果写入推演记录。
- 只有成功成交才扣除灵石并发放物品；落败和主动退出不会扣款。

## 界面与存档

- 主界面只在拍卖开放时显示限时入口，不长期占用核心推演区域。
- 弹窗将对手、余额、剩余时间、拍品描述、准入、价格和落槌状态拆成可扫描组件。
- 正式竞价继续使用全局抉择组件，确保玩家亲自决定且其他行动暂时锁定。
- 拍卖状态与最近落槌记录写入 JSON，并为旧存档提供空拍卖默认值。
