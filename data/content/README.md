# 内容与存档分层

《问道长生》当前不使用数据库，内容按用途分成四层：

- `docs/修仙模拟器 · 问道长生.docx`：用户原始文案，是规则与世界观的权威来源。
- `data/content/`：适合策划调整的结构化静态内容，例如网页抉择文案与按钮说明，随 Git 版本发布。
- `src/xiuxian_simulator/`：必须精确、可测试的数值规则和状态机。
- `data/saves/*.json`：每一局会变化的本地存档；不会提交到 GitHub。

本地单人游戏的数据量小、没有并发写入，也不需要复杂查询，因此现阶段使用 JSON 比数据库更透明、更容易备份和迁移。若未来出现数百名动态 NPC、跨存档世界、模组索引或大量查询，再将动态世界数据迁移到 SQLite；静态剧本内容仍应保留为可审查的 JSON 文件。
